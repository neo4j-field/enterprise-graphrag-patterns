# GraphRAG experiments

Small, practical Neo4j GraphRAG experiments designed to answer common customer questions.

## Experiments

- [Source provenance](source-provenance/) — preserve the provenance of entities and relationships extracted from document chunks while exposing a deduplicated domain graph.
- [Entity resolution](entity-resolution/) — merge and split entities extracted from documents, reconcile them with structured records, and retain an optional audit trail for resolution decisions.
